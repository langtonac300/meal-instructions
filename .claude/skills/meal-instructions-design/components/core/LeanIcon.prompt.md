Brand "Lean 5S" glyph for proteins, appliances and process metrics (temp, time, flip, probe, rest, spray, scale, safety) — the icon vocabulary of every spec cell and filter bar.

```jsx
<LeanIcon name="chicken" size={20} style={{ color: 'var(--accent)' }} />
<LeanIcon name="heat-waves" size={24} />          // temp
<LeanIcon name="appliance-air-fryer" size={28} />
```

Aliases accepted: protein slugs (chicken, beef, seafood…), appliance slugs (air-fryer, sheet-pan, cast-iron…), metric names (temp, time, flip, probe, rest, spray, scale, safety, speed). Color via CSS `color` — ink at rest, ink-muted/subtle for secondary, accent for the live/critical metric.
