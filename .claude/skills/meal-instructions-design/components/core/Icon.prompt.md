Lucide-style generic UI icon (search, x, zap, clock, play, printer…); use for chrome, never for food/appliance/process metrics (use LeanIcon for those).

```jsx
<Icon name="search" size={14} style={{ color: 'var(--ink-subtle)' }} />
<Icon name="star" size={20} fill="currentColor" />
```

Sizes used in the product: 12, 14, 16, 20. Stroke is always 2. Color comes from CSS `color`.
